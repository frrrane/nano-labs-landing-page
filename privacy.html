Norn Labs Privacy policy

Privacy policy

Last updated 24 August 2026

Norn Labs is the name of an independent project run by one individual. It is not a registered company, and references to "Norn Labs" below mean that person acting in a personal capacity — who is also the data controller for anything described here. Contact details are at the foot of this page.

This policy covers this website and NornPulse, the short-form video engine published at nornpulse.nornlabs.ai.

The short version

NornPulse does not have user accounts. You cannot sign in to it, and it never asks you to connect a Google or YouTube account. The only YouTube accounts it touches are those owned by Norn Labs itself.

This website

This site is static and hosted on GitHub Pages. It sets no cookies, runs no analytics, and includes no tracking or advertising scripts. Fonts are loaded from Google Fonts, which receives the request as a normal part of serving the file.

GitHub records server logs, including visitor IP addresses, when it serves these pages. That processing is GitHub's, described in the GitHub Privacy Statement. Norn Labs does not receive or store those logs.

The NornPulse demo

The demo at nornpulse.nornlabs.ai runs in read-only mode. It has no login, collects no personal information, and does not profile visitors. Streamlit's own usage telemetry is disabled.

If you upload a video file to the demo, that file is processed to produce a result and is not published anywhere, shared with anyone, or used to train any model. Do not upload material you do not have the rights to, or that contains information you would not want processed by a third-party model provider.

Google and YouTube data

NornPulse uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

It accesses Google user data in two distinct ways:

  • An API key, for public information only — the public trending chart and public view, like and comment counts on public videos. This involves no account access and no personal data.
  • OAuth, granted by the operator of this project, for the YouTube channels they personally own. The scopes requested are youtube.upload, to publish videos to those channels, and youtube.readonly, to read back their statistics. No other person is asked for, or able to grant, this access.

Data obtained this way is used only to publish videos to those channels and to compare predicted reach against actual reach. It is stored in a private ClickHouse database controlled by the operator, and consists of video identifiers, titles, tags, predictions and public performance counts.

It is never sold, never shared with third parties, never used for advertising, and never used to train machine-learning models. Norn Labs' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Third parties that process data

Producing a video involves sending the source material and its transcript to model providers. NornPulse uses Google's Gemini and Lyria models, and ClickHouse Cloud for storage. Each processes that data under its own terms.

Revoking access

Access granted to NornPulse can be revoked at any time at myaccount.google.com/permissions. Revoking it immediately ends the application's ability to reach the account.

To request deletion of stored data relating to a channel, email the address below; records will be removed within 30 days.

Retention

Video metadata and performance records are kept while they remain useful for measuring forecast accuracy, and deleted on request.

Contact

Questions about this policy, or a deletion request: nornlabs@gmail.com.
